# ADR 0001：采用自研显式状态机作为后续编排核心

- 状态：Accepted
- 日期：2026-07-13
- 决策范围：M1 架构选择；状态机实现留到 M2

## 背景

项目要求工作流状态、授权、预算、审批与副作用语义可以独立验证，并且核心 domain、
policy 和 tool executor 不能依赖 LangGraph 类型。M1 已经建立 `workflow_run` 的稳定身份、
版本、初始状态与预算，以及与工具调用和审计事件的关联。

## 决策

M2 将在核心包中实现自研的显式有限状态机。允许在边界层增加 LangGraph 等框架适配器，
但持久化状态、合法迁移、预算检查、审批停点和恢复语义由项目自己的 domain/service 层定义。

## 影响

- 状态迁移可以用确定性单元测试和数据库约束独立验证。
- 工具授权与幂等执行器继续保持框架无关。
- 需要自行实现 checkpoint 驱动与恢复循环；这属于 M2/M4，不在 M1 提前实现。
